Decision Log

Decision Reason Tradeoff
Use Asio behind TcpConnection and TcpListener. The project already depends on Asio, and it removes duplicated platform socket code from the app files. The implementation now depends on Asio semantics, but the app-facing API remains small enough to replace later.
Use a 16-byte frame header. Adding format and compression fields now avoids another protocol break when H264 or other formats are added. External old-protocol clients need updates. The C++ server and client remain compatible with each other.
Represent H264 as a stub enum value only. The abstraction needs a future compression slot, but Phase 1 should not pretend to implement encoding or decoding. Compressed payload validation is intentionally minimal until a real codec layer exists.
Keep stats on data ports. The UI needs consistent snapshots with strings, so data ports fit better than atomic structs. Stats delivery can drop snapshots under pool pressure, which is acceptable for UI telemetry.
Delay app shell extraction until after endpoint and GL adapters. The render/capture ordering is the highest-risk part, so the lower-level boundaries were stabilized first. Temporary duplication remained in the app files until Phase E.
Make GlApp callback-based instead of subclass-based. The apps are small and already organize behavior around per-frame steps: poll data, draw panels, and optionally capture after render. Callbacks are less extensible than a full application framework, but avoid introducing inheritance and keep ownership obvious in main().
Put DockSpace setup inside GlApp. Both stream apps need the same fullscreen dockspace every frame, and it is part of the ImGui frame shell rather than app-specific stream logic. Apps that need a different root layout must disable docking in GlAppConfig or extend the shell later.
Keep GL texture adapters owned by the app, not by GlApp. The capture and display textures are stream-domain resources, while GlApp should only own window and ImGui lifecycle. The app must destroy these resources before GlApp destructs so OpenGL cleanup happens while the context is current.
